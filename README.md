Welcome to my personal website! This is a modern, responsive website built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

Visit the live site at: **https://m-elfeki.github.io** (or https://melfeki.github.io depending on your GitHub username)

- **Modern Design**: Clean, professional design with smooth animations

## 🛠️ Customization

### Update Personal Information

1. **Name and Title**: Edit the hero section in `index.html`
2. **About Section**: Update the about text in the About section
3. **Skills**: Modify the skill tags in the About section
4. **Projects**: Add your projects in the Projects section
5. **Contact Links**: Update the contact links (GitHub, Email, LinkedIn) in the Contact section

### Change Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #2563eb;    /* Change this for primary color */
    --secondary-color: #1e40af;  /* Change this for secondary color */
    /* ... other variables ... */
}
```

## 📝 Publishing to GitHub Pages

### Step 1: Push Your Code to GitHub

If you haven't already, commit and push your changes:

```bash
git add .
git commit -m "Add personal website"
git push origin main
```

### Step 2: Enable GitHub Pages

1. Go to your repository on GitHub: `https://github.com/M-Elfeki/melfeki.github.io`
2. Click on **Settings** (top menu)
3. Scroll down to **Pages** in the left sidebar
4. Under **Source**, select **main** branch
5. Select **/ (root)** folder
6. Click **Save**

### Step 3: Access Your Website

Your website will be available at:
- **https://m-elfeki.github.io** (or https://melfeki.github.io)

> ⚠️ **Note**: It may take a few minutes for GitHub Pages to deploy your site. You'll see a green checkmark when it's ready!

## 🔄 Updating Your Website

Whenever you make changes to your website:

1. Edit the files locally
2. Commit and push the changes:
   ```bash
   git add .
   git commit -m "Update website content"
   git push origin main
   ```
3. GitHub Pages will automatically rebuild your site within a few minutes
